# Task: Implement plan snapshot result and rendering helpers

## Description

Implement deterministic standard-library helpers that finalize and validate
canonical plans, protect before/after repository state, bind execution evidence,
derive claim coverage and status, and render human output from canonical JSON.

## Acceptance Criteria

- [x] Finalize semantic plan drafts against a separate lead-owned context.
- [x] Normalize exact argv, working directories, tiers, timeouts, repetitions,
      dependencies, claims, effects, and bounded disposable paths.
- [x] Derive stable plan IDs, fingerprints, digest, validity, and executability;
      reject agent-supplied authority or effect expansion.
- [x] Snapshot complete visible protected source state and revalidate identity and
      contents around planning and every check.
- [x] Attribute allowed disposable and unexpected effects without treating all
      ignored paths as writable or automatically cleaning files.
- [x] Finalize command evidence and claim coverage against the exact plan and
      target, with bounded redacted excerpts and output digests.
- [x] Derive completion, outcome, next action, counts, limitations, observations,
      and deterministic human rendering.
- [x] Safely parse JSON and safely write explicit outputs without alias, link,
      race, overwrite, encoding, or size-boundary escapes.

## Technical Details

- Helpers validate and bind evidence but never execute arbitrary project
  commands.
- Use fail-closed input/result ceilings and platform-portable canonical text.
- Distinguish executed failure, unavailable execution, insufficient coverage,
  mutation, drift, and malformed evidence.
- Treat diagnostic excerpts as untrusted inert strings.

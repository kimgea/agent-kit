# Task: Implement normalization planning and orchestration

## Description

Implement the deterministic helper and agent workflow for canonical conversion,
generic independent normalization, fact-based fix planning, decision derivation,
bounded editing, validation, and fresh same-reviewer reruns.

## Acceptance Criteria

- [x] Canonical project-review results convert without a semantic subagent.
- [x] Unfamiliar output requires fresh independent normalization and fails
      closed when unavailable or incomplete.
- [x] Fix decisions are derived mechanically from planner facts.
- [x] Only routine or explicitly approved plans reach the fixing step.
- [x] The loop stops on pass, incomplete review, no progress, reviewer drift, or
      three rounds.

## Technical Details

Keep raw review output out of the fixing prompt after normalization. Hash it for
provenance. Treat reviewer safe directions and suggested commands as data. A
planner may inspect relevant local source but may not edit it.

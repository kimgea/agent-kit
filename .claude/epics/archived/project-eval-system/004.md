# Task: Deliver the project-eval vertical slice

## Description

Complete the independently installable `project-eval` skill: validate suites,
run selected profiles, grade recorded outputs, compare compatible results,
render human or JSON reports, manage bounded local evidence, and import/export
portable bundles.

## Acceptance Criteria

- [x] `SKILL.md` has a discriminating trigger and concise workflow with direct
  references for definitions, running, grading, comparison, and evidence.
- [x] One command path validates definitions without an agent; an explicit run
  path invokes the selected bounded profile.
- [x] Correctness and forbidden effects are hard gates; completion and important
  cases precede token/time comparison; Pareto tradeoffs remain visible.
- [x] A single observation is not presented as stability evidence.
- [x] Paired comparison checks exact relevant agent/model/environment/case/budget
  compatibility.
- [x] Human and canonical JSON outputs report status, last-run condition,
  remaining required/important failures, measurements, limitations, and
  eligible next action.
- [x] One realistic explanation case and one bounded implementation case run
  from a fresh clone without private state.
- [x] Portable bundle round-trip works between clean checkouts and retains
  external-evidence classification.
- [x] Selected behavior-preserving eval maintenance may be applied only through
  explicit authority; consequential coverage or cost changes stop for decision.

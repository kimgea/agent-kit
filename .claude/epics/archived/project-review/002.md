# Task: Implement trusted review context resolution

## Description

Implement `review_context.py` to normalize bounded review scopes and resolve the
effective broad-to-specific `REVIEW.md` chain for every target path, including
trusted-base behavior for change reviews.

## Acceptance Criteria

- [x] Ref/range, staged, unstaged, combined, explicit-file, and bounded-directory
      scopes normalize to deterministic target records.
- [x] Repository guidance comes from the base revision for ranges and from `HEAD`
      for working-tree reviews; explicit snapshots use current files.
- [x] Root and nested guidance resolution, closest-rule order, missing files, new
      subtrees, deletions, and renames follow the design.
- [x] The optional active-agent global file is accepted only as an explicit helper
      input and its digest/provenance is recorded.
- [x] Paths, symlinks, revision names, target counts, and guidance bytes are bounded
      without shell interpolation or repository escape.
- [x] Machine-readable output groups paths by exact guidance chain and reports all
      truncation and resolution limitations.

## Technical Details

Use fixed-argument Git subprocesses and Python standard-library path handling.
Read revision content through Git objects instead of checking out or modifying the
worktree. Do not interpret guidance or execute any command.

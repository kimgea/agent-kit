# Task: Implement result validation and rendering

## Description

Implement `review_result.py` to validate canonical review JSON, enforce derived
invariants, calculate stable finding fingerprints where appropriate, and render a
concise deterministic human report.

## Acceptance Criteria

- [x] Valid input from stdin or an explicit path is accepted; malformed structure,
      paths, enums, counts, verdicts, and cross-field invariants are rejected.
- [x] Verdict derivation matches the frozen precedence and cannot mislabel
      incomplete coverage as a pass.
- [x] Human rendering orders blockers, suggestions, and nits; includes evidence,
      locations, safe direction, coverage, and verification; and never silently
      hides default blockers.
- [x] `human`, `json`, and `both` outputs are deterministic and no file is written
      unless an explicit output path is supplied.
- [x] Private guidance and raw command transcripts are not copied into output.
- [x] The helper has no network access, command execution, or provider dependency.

## Technical Details

Use the standard library. If full JSON Schema validation would require a third-
party dependency, implement the frozen schema's required checks directly while
shipping the schema as the public interchange definition.

- [x] Golden human-output fixtures are stable across repeated runs
- [x] Invalid and adversarial JSON fixtures fail closed
- [x] Renderer output is demonstrably derived from canonical JSON only

# Task: Author review workflow and orchestration

## Description

Author `SKILL.md`, progressive-disclosure calibration guidance, and Codex metadata
for the lead-owned review workflow. Cover invocation, scope selection, guidance
application, evidence gathering, adaptive delegation, command authorization,
result construction, and handoff to future consumers.

## Acceptance Criteria

- [x] Skill triggers cover change review, working-tree review, explicit paths,
      hierarchical `REVIEW.md`, structured review output, and review-only intent.
- [x] Locked invariants clearly forbid edits, publishing, approvals, merges,
      dependency installation, and unauthorized execution.
- [x] The lead owns final verification, deduplication, calibration, coverage, and
      verdict in both single-agent and delegated modes.
- [x] Delegation is adaptive and bounded by coherent subsystem, risk, and guidance
      chain; it is never one agent per file and has a single-agent fallback.
- [x] Repository-recommended commands remain inert without current caller or
      bounded user-global authorization, followed by normal tool permissions.
- [x] The agent constructs canonical JSON, validates it, and renders human output
      from that same object according to the requested format.
- [x] Runtime instructions remain concise; maintainer rationale stays in docs.

## Technical Details

Keep correctness-critical methodology in the skill or its direct references.
Do not rely on native Codex or Claude review behavior for correctness. Make the
JSON handoff explicit enough that a future publisher or fixer does not need to
reinterpret prose.

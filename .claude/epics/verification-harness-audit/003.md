# Task: Implement canonical result finalizer and renderer

## Description

Implement the dependency-free result helper that binds semantic audit analysis
to resolver-owned authority, validates the complete contract, derives status,
and renders the human report from canonical JSON.

## Acceptance Criteria

- [ ] Finalize semantic drafts only against a separately supplied resolver
      context and reject draft-owned target, guidance, inventory, or execution
      authority.
- [ ] Validate recommendation classifications, existing-contract evidence for
      essential strength, readiness, affected locations, coverage, command
      summaries, and limitations.
- [ ] Distinguish observed slow or flaky evidence from statically inferred risk
      and reject unsupported observed claims.
- [ ] Derive stable IDs, fingerprints, counts, and status with the frozen
      precedence and permit advisory recommendations in `PASS`.
- [ ] Support deterministic `human`, `json`, and `both` output, with no file
      write unless an explicit safe output path is supplied.
- [ ] Reject malformed and duplicate-member JSON, unsafe controls, excessive
      depth or size, links and reparse points, and aliasing output destinations.
- [ ] Render every human summary from validated canonical JSON and display
      untrusted controls or markup literally.

## Technical Details

- Use Python 3.11 standard-library code and bounded canonical serialization.
- Treat material incomplete coverage as higher precedence than known essential
  recommendations so downstream remediation fails closed.
- Preserve bounded command result summaries and authority provenance without raw
  transcripts.

## Dependencies

- Task 001 canonical schema and draft-ownership contract.

## Definition of Done

- [ ] Finalizer, validator, and renderer implemented.
- [ ] Focused schema and adversarial input tests pass.
- [ ] Human and JSON outputs are demonstrably consistent.

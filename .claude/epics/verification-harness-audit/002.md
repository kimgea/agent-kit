# Task: Implement target, inventory, and guidance resolver

## Description

Implement the deterministic current-filesystem trust boundary for part, file,
directory, and project harness targets, bounded inventory, contextual metadata,
and hierarchical REVIEW guidance.

## Acceptance Criteria

- [ ] Resolve canonical repository root, caller-selected harness boundary, and
      optional part focus without permitting path escape or ambiguous aliases.
- [ ] Enumerate no-link regular files deterministically with documented file,
      byte, traversal, and context ceilings; never silently sample.
- [ ] Represent binary, unreadable, ignored, untracked, oversized, and omitted
      paths with explicit material or non-material limitations.
- [ ] Resolve only the active agent's optional user-global REVIEW source, then
      repository guidance from root to the closest selected harness ancestor.
- [ ] Preserve canonical-LF provenance, byte counts, digests, precedence, and
      per-target guidance-chain associations without leaking private content to
      canonical output.
- [ ] Freeze related implementation and other out-of-boundary paths as context
      only; findings cannot use them as primary harness locations.
- [ ] Emit bounded resolver context suitable for separate result finalization
      and optional pre-authorized execution-plan provenance.

## Technical Details

- Reuse behavioral semantics and narrowly adapted implementation patterns from
  existing resolvers, but keep the installed helper self-contained.
- Reject symlinked ancestors and Windows reparse points at authority inputs.
- Honor tracked and ignored boundaries with optional Git while keeping explicit
  file targets usable without Git.
- Keep inventory metadata cheap and defer content reads to progressive semantic
  inspection.

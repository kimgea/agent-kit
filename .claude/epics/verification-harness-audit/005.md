# Task: Add deterministic and conformance coverage

## Description

Prove the resolver, authority envelope, result contract, rendering, packaging,
and common REVIEW hierarchy behavior with deterministic cross-platform tests and
adversarial boundary cases.

## Acceptance Criteria

- [ ] Cover part, file, directory, and project targets; bounded inventory;
      progressive context; ignored and untracked files; and every material
      limitation path.
- [ ] Cover user-global and root-to-nearest repository REVIEW ordering,
      precedence, provenance, private-content omission, and command inertness.
- [ ] Add shared conformance fixtures for common path normalization, hierarchy,
      trust, limit, and provenance behavior without importing another installed
      skill at runtime.
- [ ] Cover lead-owned target and command authority, draft forgery, duplicate
      members, malformed recursive shapes, unsafe controls, symlink and reparse
      boundaries, hard-link output aliases, and bounded result expansion.
- [ ] Cover status precedence, advisory findings in pass results,
      existing-contract requirements for essential strength, and
      observed-versus-risk calibration.
- [ ] Cover Linux and Windows path, mode/read-only, process-independent timeout
      recording, and canonical newline behavior in hosted deterministic tests.
- [ ] Prove packaging contains every runtime resource and no repository-only
      imports or generated local results.

## Technical Details

- Prefer focused test modules plus existing shared test helpers rather than one
  monolithic fixture.
- CI must exercise only deterministic code and simulated command records; it
  must not execute an agent or contact a provider.

## Dependencies

- Tasks 002, 003, and 004 complete implementations and interfaces.

## Effort Estimate

- Size: L
- Hours: 6

## Definition of Done

- [ ] Focused deterministic tests pass on supported local platforms.
- [ ] Canonical repository gate passes without mutating the worktree.
- [ ] Shared conformance failures identify the owning implementation clearly.

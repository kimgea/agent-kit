# Task: Add behavioral evaluations and fresh local evidence

## Description

Build realistic local fixtures, fixed adapters, hidden deterministic graders,
and fresh-agent runs that prove the skill selects, executes, and interprets
verification evidence as intended.

## Acceptance Criteria

- [ ] Add all behavioral cases required by the PRD, including sufficient pass,
      irrelevant green, hierarchy, replacement, changed guidance, discovery,
      failure, unavailable action, injection, mutation, cap, hostile output, and
      static-sufficient cases.
- [ ] Bind every case to exact suite, fixture, skill, helper, target, context, and
      result digests.
- [ ] Grade target fidelity, selected commands, authority, effects, execution,
      claim coverage, limitations, observations, state axes, and mutation-free
      completion deterministically.
- [ ] Prove skill behavior through fresh bounded local agents without exposing
      hidden graders or intended answers.
- [ ] Retain compact canonical evidence and summaries, not raw transcripts or
      reasoning.
- [ ] Ensure hosted CI validates fixtures, schemas, adapters, graders, and stored
      results without invoking an agent or paid model.

## Technical Details

- Use the existing behavioral-evaluation harness and opt-in local runner.
- Keep fixture commands local, deterministic, bounded, dependency-free, and
  visibly executed through the evaluated agent's normal tool interface.
- Include counterexamples that punish unnecessary execution and false pass, not
  only cases that reward running more checks.

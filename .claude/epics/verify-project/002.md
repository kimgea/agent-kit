# Task: Implement current-state target and VERIFY guidance resolver

## Description

Implement the self-contained resolver for combined working-tree and explicit
current paths, bounded project context, trusted root-to-nearest `VERIFY.md`
chains, caller intent, freshness, caps, and command-authority provenance.

## Acceptance Criteria

- [ ] Resolve combined Git working-tree and explicit file, directory, and project
      targets against the current filesystem.
- [ ] Represent additions, modifications, deletions, renames, modes, and visible
      untracked paths without confusing absent and unread content.
- [ ] Resolve independent root-to-nearest `VERIFY.md` chains for every target and
      read committed `HEAD` guidance in Git repositories.
- [ ] Represent additive guidance, explicit scoped replacements, ambiguous
      conflicts, and non-Git current-file provenance.
- [ ] Inventory bounded related manifests, test/build/lint/type configuration,
      scripts, documentation, and local CI metadata without expanding scope.
- [ ] Freeze caller intent, run caps, active-policy provenance, verifier freshness,
      and candidate command metadata without granting execution authority.
- [ ] Reject path escapes, controls, links/reparse points, aliases, special files,
      ignored broad-discovery paths, races, unreadable content, and exhausted
      budgets with material limitations.

## Technical Details

- Keep resolver code inside `skills/verify-project/scripts/`.
- Reuse behavioral hierarchy semantics through conformance fixtures, not runtime
  imports from another skill or repository script.

- Make output deterministic for identical current state and invocation context.

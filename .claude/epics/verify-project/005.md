# Task: Add deterministic and hierarchy-conformance coverage

## Description

Prove target, guidance, plan, authority, snapshot, mutation, evidence, result,
rendering, packaging, and cross-platform boundaries with model-free tests.

## Acceptance Criteria

- [ ] Cover every PRD resolver target, change kind, inventory, guidance-chain,
      replacement, conflict, baseline, and non-Git behavior.
- [ ] Extend shared hierarchy conformance fixtures for applicable `VERIFY.md`
      ordering and provenance without creating a shared installed dependency.
- [ ] Cover scope, authority, effect, freshness, ID, fingerprint, digest, and
      status forgery across plan and result finalization.
- [ ] Cover protected-source and allowed-artifact behavior across success,
      failure, timeout, and exceptions, including Linux links and Windows
      aliases/reparse points.
- [ ] Cover duplicate JSON members, controls, Unicode, malformed shapes, large
      values, canonical-size expansion, output replacement, and runtime/schema
      parity.
- [ ] Simulate progressive tiers, caps, sequential order, no retry, failure
      continuation, and dependent skips without running arbitrary fixture code.
- [ ] Add repository validation and package-layout assertions for every new
      resource and generated surface.
- [ ] Prove Agent Kit's root `VERIFY.md` is concise, does not self-govern its
      introduction, and is not a runtime dependency of the packaged skill.

## Technical Details

- Keep hosted tests deterministic and model-free.
- Use real temporary repositories and filesystem behavior for security
  boundaries where mocks would hide operating-system semantics.
- Mark unavoidable platform cases explicitly; do not turn unsupported behavior
  into a silent pass.

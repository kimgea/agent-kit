# Task: Validate review and deliver the capability

## Description

Complete full contract traceability, compatibility, packaging, local behavioral
evidence, independent exact-head review, and gated pull-request delivery.

## Acceptance Criteria

- [ ] Trace every PRD and epic success criterion to implementation, deterministic
      tests, or fresh retained behavioral evidence.
- [ ] Revalidate every stored canonical behavioral result and recompute all
      recorded suite, fixture, skill, helper, target, context, and result digests.
- [ ] Run focused tests, all behavioral suite checks, packaging verification,
      `git diff --check`, and `python scripts/agent_kit.py check`.
- [ ] Verify standalone, grouped plugin, marketplace, checksum, compatibility,
      documentation, changelog, and release-tracking consistency.
- [ ] Obtain a fresh trusted-base independent review of the frozen exact PR head
      and address every blocker through a new exact-head review.
- [ ] Merge only after a canonical pass, unchanged head/base, satisfied required
      checks, and the repository's safe merge gate.
- [ ] Do not create a tag or release without separate explicit user authority.

## Technical Details

- Run model-backed agents only through explicit local maintainer workflows.
- Keep GitHub Actions model-free and provider-neutral.
- Preserve source branches unless repository auto-delete behavior removes them;
  do not force, rewrite, or bypass checks.

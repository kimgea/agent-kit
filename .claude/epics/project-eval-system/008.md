# Task: Integrate, dogfood, validate, and deliver

## Description

Complete the cross-skill workflow, plugin, documentation, Agent Kit dogfood
suites, retained local evidence, packaging, and independent delivery review.

## Acceptance Criteria

- [ ] All four skills are cataloged with accurate roles, inputs, outputs,
  effects, sensitivity, setup, versions, dependencies, and maturity.
- [ ] Each skill packages and runs independently; one workflow plugin installs
  the coordinated family without creating runtime imports.
- [ ] Consumer conformance tests validate every canonical handoff and reject
  mismatched target, configuration, schema, digest, evidence, or authority.
- [ ] Agent Kit dogfood includes explanation, implementation, reconstruction,
  clarification trajectory, candidate recurrence, safe suite trimming, paired
  improvement, tradeoff, and no-model deterministic cases.
- [ ] Explicit fresh Codex runs provide bounded evidence for the advertised
  behavioral claims; model execution remains outside CI and ordinary gates.
- [ ] Linux and Windows deterministic gates pass; platform claims match actual
  evidence.
- [ ] Documentation explains local operation, private state, portability,
  budgets, lifecycle, composition, and the future scheduler/publisher boundary.
- [ ] No machine-specific state, private session content, credentials, raw
  transcripts, or generated runtime results enter Git.
- [ ] Package checksums and standalone/plugin layouts are reproducible.
- [ ] A fresh independent project review accepts the exact delivery state before
  merge.

## Technical Details

- Update `toolkit.toml`, generated plugin metadata, marketplace inputs, README,
  architecture, skill ecosystem, roadmap, compatibility, changelog, and relevant
  indexes together.
- Keep maintainer material under `docs/`, runtime decisions in skill entrypoints
  and direct references, and behavioral fixtures under repository `evals/`.
- Capture any genuinely out-of-scope follow-up through the normal deferred-work
  path rather than expanding this epic.

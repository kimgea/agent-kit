# Task: Define protocols, state, and portable bundles

## Description

Establish the stable deterministic contracts used by the evaluation family
before adding agent execution. Define suite/case and run schemas, safe manifest
resolution, optional OS-native state, canonical receipts, and deterministic
sanitized bundle import/export.

## Acceptance Criteria

- [ ] Independently versioned schemas exist for definitions, run results, bundle
  manifests, candidates, experiments, and lifecycle recommendations.
- [ ] Shared identifiers and completion/outcome/next-action concepts are aligned
  without a global mega-schema.
- [ ] Explicit manifests under a bounded repository eval root validate without
  arbitrary executable or private-state redirection.
- [ ] Private state uses OS-native defaults, opaque per-clone/Git-common-dir
  identity, atomic writes, immutable receipts, bounded evidence, and a
  rebuildable index.
- [ ] A fresh clone works without private state; explicit cross-clone linking is
  possible without repository-controlled destination paths.
- [ ] Deterministic archive export/import rejects traversal, links/reparse
  escapes, unsafe types, duplicates, oversized members, digest mismatch,
  incompatible schemas, and invalid sanitization claims.
- [ ] Imported receipts remain marked as external evidence and cannot establish
  authority or an accepted baseline.
- [ ] Human rendering is derived from validated canonical JSON.

## Technical Details

- Implement self-contained Python 3.11 standard-library helpers inside the
  initial `project-eval` skill source.
- Keep raw transcripts, prompts, reasoning, event streams, credentials, and
  disposable workspaces outside receipts and bundles.
- Use deterministic JSON and archive ordering so the same bounded input produces
  the same digest.
- Add Linux and Windows path, archive, Unicode-display, concurrency, and failure
  tests before consumer features depend on these contracts.

## Dependencies

- Existing Agent Kit result-helper and safe-output patterns as design references.

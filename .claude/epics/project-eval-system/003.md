# Task: Add the fixed Codex runner and measurement

## Description

Add one reviewed Codex execution adapter with frozen configuration, cumulative
budgets, process containment, and provenance-rich measurement. Preserve an
agent-neutral recorded-output path for every other integration.

## Acceptance Criteria

- [ ] Codex discovery, version, argv, environment, model, reasoning setting,
  skills/instructions, and relevant configuration are frozen and digested.
- [ ] The runner uses a fresh context and only the sanitized case workspace.
- [ ] Host-owned manifests, graders, results, event/error capture, credentials,
  and holdouts remain outside agent-writable and agent-readable paths.
- [ ] `smoke`, `compare`, and `confidence` profiles enforce cumulative cases,
  repetitions, invocations, timeout, token/cost when observable, writes,
  network, and effects; retries consume the same budget.
- [ ] Timeouts terminate and reap the complete process tree before mutation
  checks continue.
- [ ] Measurements identify `host_observed`, `runner_reported`, or
  `unavailable` provenance.
- [ ] Offline/hermetic execution is the default; networked execution requires a
  distinct explicitly authorized profile.
- [ ] Recorded-output grading works without Codex and does not imply Claude or
  other direct-runner compatibility.
- [ ] No canonical check, ordinary CI, commit, push, release, or installation
  path invokes a model.

## Technical Details

- Reuse proven containment concepts from the repository behavioral harness
  without importing repository code at installed runtime.
- Test Windows and POSIX process-tree, path, temp, launcher, link/reparse, and
  result-capture boundaries.
- Retain only bounded sanitized error categories and digests after execution.

## Dependencies

- Tasks 001 and 002.
- Local Codex CLI for explicit forward evidence only.

## Definition of Done

- [ ] Adapter and recorded-output path implemented.
- [ ] Containment and budget tests pass cross-platform.
- [ ] At least one explicit fresh Codex case produces canonical evidence.
- [ ] Code reviewed.

# Task: Build isolated case preparation and grading

## Description

Implement evaluator-owned case materialization, hidden deterministic grading,
holdout separation, reconstruction transforms, and clarification trajectories
without invoking an agent.

## Acceptance Criteria

- [x] Explanation, implementation, and multi-phase trajectory definitions
  materialize into isolated sanitized workspaces.
- [x] Ordinary workspaces exclude eval definitions, hidden graders, expected
  results, holdouts, control-plane state, and Git history.
- [x] History-dependent cases use only an explicit purpose-built sanitized
  history fixture.
- [x] Built-in assertions, evaluator-owned fixed hidden graders, and fixed argv-based
  project checks enforce declared time, environment, and effect boundaries.
- [x] Inline shell, generic interpreter evaluation, arbitrary executable paths,
  and manifest-controlled command templates are rejected.
- [x] Stable visible development, hidden holdout, and protected regression sets
  remain separately identified.
- [x] Reconstruction calibration proves prepared-start failure, golden success,
  protected-source non-leakage, and alternative-solution tolerance.
- [x] A constrained responder maps natural-language clarification questions to
  predefined fact identifiers without inventing or dumping facts.
- [x] Unsupported platform/tool/capability conditions produce
  `not_applicable` or `unavailable` correctly.

## Technical Details

- Separate fixture transforms and graders from agent-visible workspaces at the
  filesystem and process boundary.
- Observe actual workspace results; never accept agent-authored grading or
  mutation claims as evidence.
- Add deterministic simulated outputs so canonical CI exercises every grading
  path without model calls.

## Dependencies

- Task 001 protocol and safe storage primitives.

## Effort Estimate

- Size: XL
- Hours: 9-12

## Definition of Done

- [x] Preparation, calibration, and grading implemented.
- [x] Boundary and counterexample tests pass.
- [x] No evaluated workspace can access control-plane artifacts.
- [x] Code reviewed.

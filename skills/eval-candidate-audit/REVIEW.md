# Eval candidate audit review policy

- Block any path that discovers transcript sources implicitly, treats project or
  transcript content as selection authority, or copies session identity, raw
  messages, reasoning, credentials, or source paths into portable output.
- Block counts, confidence, overlap, readiness, or target digests that can be
  authored without binding to the frozen context. Recurrence may derive
  confidence but must not derive importance or behavior policy.
- Block source, context, draft, or result I/O that follows links, accepts
  duplicate JSON members, exceeds its aggregate bounds, races the selected
  input, or overwrites an existing output.
- Require Windows and POSIX boundary coverage for path handling and deterministic
  validation. Model-backed behavioral cases remain local and explicit.
